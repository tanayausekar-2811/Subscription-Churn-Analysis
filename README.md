# Subscription Churn Prediction 📊
End-to-end churn prediction using Python and Power BI

The Goal: "Predicting which subscribers are likely to cancel to improve retention."

The Tech: Python, Scikit-Learn, Pandas, Matplotlib.

The "Win": State your model's accuracy or F1-score.

## Project Overview
This project predicts customer churn using a dataset of subscription users. It includes a machine learning pipeline and a Power BI dashboard for business insights.

## Project Steps
1. **Data Cleaning:** Handled missing values and outliers.
2. **EDA:** Identified key churn drivers like contract type and monthly charges.
3. **Modeling:** Trained a Random Forest classifier to predict at-risk users.
4. **Visualization:** Built a Power BI dashboard to track churn KPIs.

## Tools Used
* Python (Pandas, Scikit-Learn)
* Google Colab
* Power BI
